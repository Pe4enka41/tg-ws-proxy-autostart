# TG WS Proxy Auto

Автозапуск локального прокси [TG WS Proxy](https://github.com/Flowseal/tg-ws-proxy) вместе с Telegram Desktop для Windows.

Прокси автоматически стартует, когда запускается Telegram, и закрывается, когда Telegram полностью закрыт.

## Что делает

- Запускает `TgWsProxy_windows.exe` при старте Telegram.
- Закрывает прокси после полного выхода из Telegram.
- Перезапускает прокси, если он упал или был закрыт, пока Telegram работает.
- Работает в фоне, без окон и консоли.
- Ведёт лог: `%LOCALAPPDATA%\TgWsProxyAuto\watch.log`.

## Установка

### Вариант 1 — готовый архив (рекомендуется)

1. Скачайте `TgWsProxy-Auto-Share.zip` со страницы [Releases](https://github.com/semenmuhametev4-prog/tg-ws-proxy-autostart/releases/latest).
2. Распакуйте архив в любую папку.
3. Запустите `install.cmd`.
4. Если Windows покажет SmartScreen — «Подробнее» → «Выполнить всё равно».

В архиве уже лежит официальная сборка прокси, ничего отдельно скачивать не нужно.

### Вариант 2 — из исходников

1. Скачайте этот репозиторий: **Code → Download ZIP**, затем распакуйте.
2. Запустите `install.cmd`.
3. Установщик сам скачает актуальный `TgWsProxy_windows.exe` с официального GitHub.

Установка не требует прав администратора: всё кладётся в `%LOCALAPPDATA%`.

## Первая настройка Telegram

1. Запустите Telegram как обычно — через пару секунд в трее появится значок **TgWsProxy**.
2. Правый клик по значку → **«Открыть в Telegram»**.
3. Telegram предложит подключить прокси — согласитесь.

Если автоматический вариант не сработал:

- правый клик по значку → **«Скопировать ссылку»**;
- отправьте ссылку себе в «Избранное» в Telegram;
- нажмите на неё в чате и подключите прокси.

Настройка делается один раз.

## Важно про закрытие Telegram

Закрытие окна Telegram крестиком **не завершает программу**: Telegram остаётся в трее, поэтому прокси продолжит работать.

Чтобы прокси действительно закрылся, выйдите из Telegram полностью:

**правый клик по значку Telegram в трее → «Выйти»**.

## Как это работает

| Файл | Назначение |
|------|------------|
| `watch.ps1` | Сторож: раз в секунду проверяет процесс `Telegram.exe` и управляет прокси. |
| `install.ps1` | Копирует файлы в `%LOCALAPPDATA%\TgWsProxyAuto` и создаёт автозапуск. |
| `TgWsProxy-Auto.vbs` | Скрыто запускает сторожа при входе в Windows (создаётся установщиком в папке автозагрузки). |
| `uninstall.ps1` | Удаляет автозапуск, сторожа и файлы прокси. |

Сторож использует мьютекс, поэтому второй экземпляр не запускается. Лог автоматически обрезается до последних 500 строк.

## Удаление

Запустите `uninstall.cmd`. Настройки Telegram не изменятся — прокси из настроек подключения можно удалить вручную.

## Требования

- Windows 10 или 11 (x64 или ARM64).
- Telegram Desktop для Windows.
- PowerShell 5.1 — встроен в Windows.

## Обновление прокси

Если установщик запускается из репозитория (без exe рядом), он скачивает актуальную версию с официального GitHub. Для готового архива можно скачать новый релиз этого репозитория.

## Если что-то не работает

- Проверьте, что Telegram установлен и запускается обычным способом.
- Посмотрите лог: `%LOCALAPPDATA%\TgWsProxyAuto\watch.log`.
- Убедитесь, что в `%LOCALAPPDATA%\TgWsProxyAuto` есть `TgWsProxy_windows.exe` и `watch.ps1`.
- Перезапустите `install.cmd`.
